# 中文算纸

中文友好的笔记式计算器（Web）：左边写说明 + 数字/算式，右边实时出结果，底部自动总计。

对标 Soulver 手机「点菜记账纸」体验。

## 在线预览

**https://jackwude.github.io/zhongwen-suanzhi/**

```bash
cd ~/.hermes/workspace/projects/zhongwen-suanzhi

```

```bash

```

## 功能

### 核心
- 左编辑 / 右结果 / 底总计
- **数字蓝色高亮**（CodeMirror）
- 混写抽数：`蒸蒸日上 128`、`锅边馍 小 15`
- 四则、括号、变量（含中文名）
- 行引用 `#1+#2`、`上一行`
- **多纸文档**侧边栏 + 可改标题 + 本地持久化
- **导出**带结果文本（复制剪贴板）
- **备份/导入**：全部算纸导出为 JSON 文件，可跨设备迁移（侧边栏底部）
- 行首 `!`：**显示结果但不计入总计**

### 中文 DSL
- `3万` / `1.2亿`
- `打八折` / `8折` / `8.5折` / `打九五折`（=9.5折）/ `打九点五折` / `十折`（原价）
- `50 + 10%` → 55；`50 * 10%` → 5
- `500 满300减50` → 450
- `单价 第二件半价` → 两件合计系数 `*1.5`
- 单位：`3斤` `2两` `1亩` `10公里` 等（折算为数值）

### 技术
- 求值：**mathjs**（开源，禁止 eval）
- 展示精度：decimal.js
- 编辑器：CodeMirror 6
- 部署：GitHub Pages（push main 自动）

## 语义摘要

| 输入 | 结果 |
|------|------|
| `菜名 128` | 128 |
| `!单价 = 89` | 显示 89，**不计总计** |
| `打八折` / `N折` | × N/10 |
| `打九五折` / `打九点五折` | × 9.5/10（多位中文数字：首位为整数位） |
| `十折` | × 1（原价） |
| `a + N%` | a × (1 + N/100) |
| `a * N%` | a × (N/100) |
| `x 满A减B` | x≥A ? x-B : x |
| `上一行 * 2` | 上一有效行 × 2 |

## 已知限制

- 首屏包约 887KB（mathjs 数字版 + CodeMirror 6）；导出图片的 html2canvas 已改为点击时懒加载
- 无小程序 / 云同步 / 账号（可用 JSON 备份跨设备迁移）
- 单位是数值折算，非带量纲运算
